# Run Pharma App

Starts the Pharma Shipment Risk Analyzer application locally.

```bash
cd "/home/labuser/Downloads/handson/Day 2 Case study"
streamlit run app.py
```

The app will open at http://localhost:8501 automatically.

## Options
- `--port 8502` - Run on different port
- `--logger.level=debug` - Enable debug logging

## What it does
- Launches the Streamlit web server
- Opens interactive data analysis dashboard
- Loads sample pharma shipment data
- Ready for Excel file uploads
