# Start Development Server

**Trigger**: User wants to run/start/launch the development server

## Description
Starts the Vite development server for the ALCOA+ QA application on localhost:3000 with hot module reloading enabled.

## Prerequisites
- Dependencies installed: `npm install`
- Working directory: project root
- Node.js 16+ installed

## Steps

1. Verify dependencies are installed
2. Start dev server with: `npm run dev`
3. Server runs on: `http://localhost:3000`
4. Watch for compilation errors
5. Access app in browser

## Output
- Server URL: `http://localhost:3000`
- Files watching for changes
- HMR (Hot Module Reload) enabled

## Notes
- Press `q` to quit the dev server
- Changes to `.env.development` require restart
- Mock data loads automatically

## Related Commands
- `npm run build` - Production build
- `npm run preview` - Preview production build
