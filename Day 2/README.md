# ALCOA+ QA Management System

A professional-grade Quality Assurance management platform designed for Eli Lilly's pharmaceutical operations, featuring complete ALCOA+ compliance and 21 CFR Part 11 adherence.

## Features

- 📊 **Dashboard**: Real-time QA metrics and ALCOA+ compliance overview
- 📋 **QA Records Management**: Create and manage test results, deviations, documentation, and audit records
- 🔍 **Audit Trail**: Complete immutable record of all system activities
- 📈 **Reports & Analytics**: Multiple report types with compliance metrics
- 🔐 **Role-Based Access Control**: Admin, QA Manager, QA Analyst, Reviewer roles
- ✓ **ALCOA+ Compliance**: Full support for Attributable, Legible, Contemporaneous, Original, Accurate, Auditable & Complete principles

## Tech Stack

- React 18 with TypeScript
- Vite
- Tailwind CSS
- Lucide React (Icons)
- date-fns (Date handling)

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`

## ALCOA+ Principles

✓ Attributable - Records identify who made them and when
✓ Legible - Records are clear and readable
✓ Contemporaneous - Records created at time of event
✓ Original - Original records are preserved
✓ Accurate - Records contain correct information
✓ Auditable & Complete - Complete audit trails maintained
