ALCOA Principles

Data Quality Framework for Compliance and Integrity

AAttributable

Data can be traced to the person who created or modified it.

✓ User identification tracked
✓ Timestamps recorded
✓ Audit trail available

LLegible

Data is clear, readable, and understandable.

✓ Clear handwriting or printing
✓ Proper formatting
✓ No ambiguous abbreviations

CContemporaneous

Data is recorded at the time an event occurs.

✓ Real-time documentation
✓ No retroactive entries
✓ Immediate recording

OOriginal

Data is recorded in its original form without alteration.

✓ No blanking or erasure
✓ Single line through errors
✓ Traceable corrections

AAccurate

Data is correct, complete, and precise.

✓ Verified for accuracy
✓ Complete information
✓ Appropriate detail level
