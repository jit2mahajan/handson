SUPPORT INFORMATION
───────────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING

Q: Progress not saving?
A: Check localStorage enabled in browser. Try different browser.

Q: Mobile layout looks wrong?
A: Check viewport meta tag. Try rotating device. Clear cache.

Q: Animations not smooth?
A: Close other applications. Check hardware acceleration enabled.

Q: Export not working?
A: Check JavaScript enabled. Try different browser.

Q: Forms not saving?
A: Check browser allows localStorage. Try non-private mode.

For more help, see IMPLEMENTATION_GUIDE.txt - Troubleshooting section.
