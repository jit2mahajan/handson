TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

ISSUE: Progress not saving
SOLUTION: Check browser's localStorage is enabled
          Try different browser
          Clear browser cache and try again

ISSUE: Animations not smooth
SOLUTION: Close other applications
          Check browser hardware acceleration enabled
          Try a different browser

ISSUE: Mobile layout looks wrong
SOLUTION: Check viewport meta tag is correct
          Try zooming out (Ctrl+- or Cmd+-)
          Rotate device to landscape/portrait

ISSUE: Export not working
SOLUTION: Check JavaScript is enabled
          Try different browser
          Check file permissions

ISSUE: Forms not saving data
SOLUTION: Check browser allows localStorage
          Try private/incognito mode (temp)
          Check browser settings
