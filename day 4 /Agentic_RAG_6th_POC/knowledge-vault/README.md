# knowledge-vault

An Obsidian vault whose entry notes cross-link to this project's real source-of-truth docs rather than duplicating them.

## Setup

Open **the repository root** (`Agentic_RAG_6th_POC/`, not this `knowledge-vault/` folder) as the Obsidian vault. Wikilinks below (e.g. `[[allowlist]]`) resolve by filename across the whole repo, so they only work if Obsidian can see `.claude/skills/pharma-rag-principles/references/` and the root `README.md`/`CLAUDE.md` — all of which live outside this folder.
